# セットアップ手順

## 必要なもの

- Google アカウント（社内）
- 日報ログSS・スケジュールSSへのアクセス権

---

## ステップ 1: GAS プロジェクトを作成する

1. [Google Apps Script](https://script.google.com) を開き「新しいプロジェクト」を作成
2. プロジェクト名を `試作課 日報・集計システム` に変更

---

## ステップ 2: コードを貼り付ける

1. 左側の「コード.gs」を選択し、既存コードを全削除
2. `Code.gs` の内容をコピーして貼り付け
3. 「＋」ボタン → **スクリプトファイル** を追加 → ファイル名を `WeeklyReport` にする
4. `WeeklyReport.gs` の内容をコピーして貼り付け
5. 「＋」ボタン → **HTMLファイル** を追加 → ファイル名を `Index` にする
6. `Index.html` の内容をコピーして貼り付け
7. 同様に `guide.html` を追加（ファイル名: `guide`）
8. 上部の「💾 保存」ボタンをクリック

---

## ステップ 3: Web アプリとして公開する

1. 右上の「デプロイ」→「新しいデプロイ」をクリック
2. 「種類の選択」で「ウェブアプリ」を選択
3. 設定：
   - **次のユーザーとして実行**: 自分
   - **アクセスできるユーザー**: 組織内全員
4. 「デプロイ」をクリック → 権限を承認
5. 表示された **Web アプリの URL** をブックマーク・共有する

---

## ステップ 4: トリガーを設定する（初回1回のみ）

GAS エディタで以下の2関数をそれぞれ選択して「▶ 実行」する：

```
setupWeeklyTrigger()   → 毎週木曜 7:00 に週次レポートを自動生成
setupMonthlyTrigger()  → 毎月1日 7:00 に月次レポートを自動生成
```

左メニュー「トリガー」から設定済みか確認できる。

---

## ステップ 5: 過去データのバックフィル（必要な場合）

過去分を一括生成する場合は `WeeklyReport.gs` の先頭にある `START_DATE_STR` を対象開始日に変更し、以下を実行：

```
generateWeeklyReportBackfill()
```

特定月の月次レポートを手動生成する場合：

```
generateMonthlyReportForMonth(2026, 5)  // 例: 2026年5月
```

---

## トラブルシューティング

| 症状 | 対処法 |
|------|--------|
| 権限エラーが出る | GAS の権限承認画面で「許可」を選択 |
| 集計レポートSSが見つからない | SSの名前が「試作課週次レポート」になっているか確認 |
| 突合できない製品がある | `debugUnmatched()` を実行して類似候補を確認 |
| SSへのアクセスエラー | `testAccess()` を実行してIDと権限を確認 |
