# 要件定義

## システムの目的

試作課の工数・労務費を日報から自動集計し、上長・生産管理課が参照できる形にする。

- 職人が毎日の作業内容を日報アプリから入力
- GAS が自動集計し、週次・月次レポートを生成
- 原価算出の根拠データとして活用

---

## ユーザー

| ユーザー | 役割 |
|---------|------|
| 試作課 職人 | 日報アプリから作業時間・作業種別を入力 |
| 試作課 上長 | 週次・月次レポートで工数・進捗を確認 |
| 生産管理課 | 原価表への転記データとして参照 |

---

## 製品試作フロー（工程と担当）

```
1. 依頼受領（企画）
2. 内容確認（試作課）
3. 部材選定（試作課）
4. 型紙作成（試作課）
5. モック作成（試作課）
6. 修正（企画+試作）
7. 1stサンプル（試作課）
8. 評価会（関係部署）
9. 2ndサンプル（試作課）
10. 原価算出（試作課）← 日報の累計工数が根拠データになる
11. 指示書作成（試作課）
12. 量産引継ぎ（試作課→現場）
```

原価表は**生産管理課が管轄**。試作課は工数データを提供する役割。

---

## 費用計算の考え方

| 項目 | 値 | 備考 |
|------|-----|------|
| 分給（日報アプリ） | **42円/分** | 間接労務費込みの概算 |
| 分給（原価表） | **36.8円/分** | 直接労務費のみ（生産管理課が管轄） |
| 間接労務費割合 | 15% | 直接労務時間85%:間接15%として算出 |

日報の労務費（42円/分）は管理用。原価表（生産管理課管轄）への転記時は 36.8円/分 ベースで算出。
