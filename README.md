# 試作課 日報・集計システム

Google Apps Script (GAS) で構築した試作課向けの日報入力・週次/月次集計システム。

---

## ファイル構成

| ファイル | 役割 |
|---------|------|
| `Code.gs` | 日報アプリのバックエンド（データ取得・提出・マスタ管理） |
| `Index.html` | 日報入力UI（バー並び替え・複製機能あり） |
| `WeeklyReport.gs` | 週次・月次集計レポート生成 |
| `guide.html` | 利用ガイドページ |
| `sample_preview.html` | UIプレビュー用 |
